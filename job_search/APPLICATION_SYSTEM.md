# Application system

## Source of truth

Use Simplify for saved jobs, applications, salary range, applied date, stage, and notes. Add direct/company-career-page applications manually if it does not capture them.

For each worthwhile application, record:

- Résumé version used
- Referral or recruiter contact
- Next action and date
- For foreign remote roles: whether India/EOR or contractor hiring is supported
- Interview notes and any rejection feedback

## Calendar

Use Google Calendar for interviews and reminders. Add a follow-up reminder only for referral or recruiter outreach, 5–7 business days after the message. Do not follow up after a rejection.

## Applying

- Prefer high-fit roles posted in the last few days.
- Use a referral or direct outreach for high-conviction roles.
- Tailor the résumé only by clarifying and reordering genuine experience; never add claims the master résumé cannot support.
- Review autofilled application answers before submitting.

## Weekly review

Review applications, replies, interviews, referrals, and portal performance once each week. Adjust alerts and application focus based on where interviews come from.
