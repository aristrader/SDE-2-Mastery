# ATS Keyword Reference

Use this as a tailoring reference, not a keyword-stuffing checklist. Include a term only when the résumé or
skills section can support it truthfully. Prefer the language used in the target job description.

## Core backend engineering

Java, Python, Golang, C++, Spring Boot, Spring Framework, Spring MVC, Hibernate, backend services, REST APIs,
microservices, API design, versioned APIs, external API integrations, OpenFeign, JSON contracts,
event-driven architecture, object-oriented programming, workflow orchestration, Maven, Gradle, Git, and GitHub.

## Distributed systems and reliability

Apache Kafka, asynchronous processing, concurrent processing, idempotency, retry and backoff, error handling,
fault tolerance, data consistency, state management, caching, Redis, job scheduling, cron, telemetry,
observability, logging, monitoring, debugging, root-cause analysis, code reviews, testing, static analysis,
technical-debt reduction, scalability, high availability, SLAs, and SLOs.

## Data, cloud, and security

MySQL, PostgreSQL, MongoDB, SQL, NoSQL, data migration, query optimization, AWS, Amazon S3, presigned URLs,
AWS KMS, envelope encryption, BYOK, multi-tenant systems, OAuth 2.0, JWT, HMAC, RBAC, PII protection,
data retention, and CI/CD.

## Performance and delivery

Performance optimization, latency reduction, throughput, p99 latency, cost optimization, end-to-end ownership,
production rollout, feature flags, customer onboarding, client integrations, technical design, SDLC, agile
delivery, documentation, cross-functional collaboration, and stakeholder communication.

## Domain terms for relevant roles only

Identity verification, KYC, OCR, document verification, document authentication, liveness detection, face
matching, fraud prevention, risk decisioning, biometric verification, audit trail, compliance, and manual review.

## Rule

Pair a keyword with scope, engineering mechanism, or result. Do not add tools, metrics, or ownership claims
solely for ATS coverage.
