# Behavioral Design Patterns

Behavioral patterns decide where behavior lives, how it is selected, and how objects collaborate at runtime.

Start with the comparison pages first. In interviews, the hard part is usually not naming Strategy or Template Method; it is explaining why one shape fits the responsibility split better than the other.

## Quick recall

**Q. What do behavioral patterns mostly organize?**
A. Runtime behavior, delegation, workflow ownership, and collaboration between objects.

**Q. What is the main interview trap?**
A. Picking a pattern name before deciding what varies, what stays fixed, and who owns the workflow.
