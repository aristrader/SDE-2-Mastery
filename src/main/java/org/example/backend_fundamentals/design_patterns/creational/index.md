# Creational Design Patterns

Creational patterns control how objects are created, named, configured, and wired together.

Use the generated topic cards below as the source of truth for the study order. Keep the order in each child page's `order` frontmatter so the hub page, sidebar, and top-level navigation stay aligned.

## Quick recall

**Q. What do creational patterns mainly solve?**

A. They move object creation decisions out of noisy caller code and into a focused construction mechanism.

**Q. Which creational patterns matter most in daily Java work?**

A. Singleton, Factory Method, Builder, static factory methods, and dependency-injection-shaped wiring.
