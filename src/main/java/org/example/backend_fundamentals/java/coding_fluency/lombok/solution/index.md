# Lombok Solutions

## Solution: value-immutable-dto - @Value immutable DTO
```java
@Value
class KycVerificationResult {
    String userId;
    String status;
    String reason;
    java.time.Instant verifiedAt;
}
```
Setters do not exist, and fields are private final.

## Solution: builder-value - @Builder + @Value build-then-lock
```java
@Value
@Builder(toBuilder = true)
class KycVerificationResult { ... }

KycVerificationResult r1 = KycVerificationResult.builder().userId("U1").status("PENDING").build();
KycVerificationResult r2 = r1.toBuilder().status("REJECTED").build();
```

## Solution: data-vs-value - @Data vs @Value mutation boundary
`@Data` generates setters and makes fields private (but non-final), meaning instances are mutable.
`@Value` generates NO setters and makes fields private final, meaning instances are immutable.

## Solution: slf4j-logging - @Slf4j structured logging
```java
@Slf4j
class KycVerificationService {
    public void verify(String userId) {
        log.debug("Starting KYC verification for userId={}", userId);
        log.info("Verification complete for userId={}, status={}", userId, "APPROVED");
        try { ... } catch (RuntimeException e) {
            log.error("Verification failed for userId={}", userId, e);
        }
    }
}
```

## Solution: requiredargsconstructor-injection - @RequiredArgsConstructor constructor injection
```java
@RequiredArgsConstructor
class KycVerificationService {
    private final KycRepository repository;
    private final NotificationService notifier;
}
```
Spring automatically uses the single constructor generated by `@RequiredArgsConstructor` for dependency injection.
