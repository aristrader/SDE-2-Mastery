# Foundations

Java foundations are the language basics used by every later module: primitive values, arrays, strings, control flow, enums, and exceptions.

## Study path

| Order | Page | Use it for |
| --- | --- | --- |
| 1 | `primitives` | Value types, defaults, wrappers, and boxing basics. |
| 2 | `arrays` | Fixed-size indexed storage before collection APIs. |
| 3 | `string` | Immutability, comparison, builders, and common string traps. |
| 4 | `control_flow` | Branching, loops, switch, and operators. |
| 5 | `enums` | Type-safe constants with fields and behavior. |
| 6 | `exceptions` | Checked vs unchecked errors and handling strategy. |

## Quick recall

- **Need a nullable number?** Use a wrapper such as `Integer`, not `int`.
- **Need resizable storage?** Move from arrays to collections.
- **Need named fixed states?** Use an enum, not string constants.
- **Need recoverable handling?** Catch narrowly; do not swallow exceptions.
