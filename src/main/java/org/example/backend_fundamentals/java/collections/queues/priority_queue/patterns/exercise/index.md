# PriorityQueue Patterns Practice

## Exercise: kth-largest-element - Kth Largest Element

Find kth largest using a min-heap of size `k`.

## Exercise: k-smallest-elements - K Smallest Elements

Find k smallest using a max-heap of size `k`.

## Exercise: top-k-frequent-numbers - Top K Frequent Numbers

Build a frequency map and use a min-heap of size `k`.

## Exercise: merge-sorted-arrays - Merge Sorted Arrays

Merge sorted arrays using a heap of cursors. Heap size should stay at most the number of arrays.

## Exercise: two-heaps-median - Two Heaps

Maintain lower half in a max-heap and upper half in a min-heap. Print median after each insertion in `5, 15, 1, 3`.
