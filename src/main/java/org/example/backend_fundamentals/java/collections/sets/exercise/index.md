# Practice

## Exercise: basic-hashset-operations - Basic HashSet Operations

### Objective
Become comfortable with `HashSet`.

### Task
Create a `HashSet<String>` and perform:

- `add`
- `remove`
- `contains`
- `size`
- `isEmpty`

## Exercise: understanding-add - Understanding add()

### Objective
Understand the boolean returned by `add()`.

### Task
Insert duplicate values. Print the return value of every `add()` call and explain the output.

## Exercise: remove-duplicates - Remove Duplicates

### Objective
Convert a list into unique values.

### Task
Given a `List<Integer>` containing duplicates, return only unique elements using a `HashSet`.

### Objective

### Task
