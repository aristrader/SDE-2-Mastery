# Practice

## Exercise: preserve-order - Preserve Order

### Objective
Learn `LinkedHashSet`.

### Task
Remove duplicates from a list while preserving insertion order.

## Exercise: linked-hash-set - Preserving Insertion Order

### Goal
See how `LinkedHashSet` solves the unpredictable iteration order of a regular `HashSet`.

### Task
Create a `HashSet<Integer>` and a `LinkedHashSet<Integer>`. Add `10`, `1`, `5`, and `20` to both. Print both sets.

### Checks
- Which set prints elements in insertion order?
- Which set prints bucket order?

## Exercise: sorting - Sorting

### Objective
Learn `TreeSet`.

### Task
Insert random integers into a `TreeSet` and print the final order.

## Exercise: mini-challenge - Mini Challenge

### Objective
Combine ordering decisions.

### Task
Given a list of words:

- remove duplicates;
- preserve insertion order;
- print alphabetically;
- print total unique count.
