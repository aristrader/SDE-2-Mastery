# Interviewer prompt — Coupon / Promotion Rules

> Design a coupon and promotion system for checkout.

This problem statement is intentionally vague. Review the
[sample candidate discussion](../candidate_discussion/) for reference, then continue to the
[final exercise](../).

Possible clarification directions include cart scope, percentage versus fixed discounts, stacking, usage limits,
and the behaviour for invalid or expired codes.

Requirements -
A coupon has following configuration -
- Fixed or percentage discount (more can be added in future)
- Eligible productIds, if restricted
- start and expiry time
- global usage limit 
Coupon system will take in the cart - product, unit price and quantities and we calculate the discount
