# Interviewer prompt — E-commerce Checkout

> Design the checkout flow for an e-commerce application.

This problem statement is intentionally vague. Review the
[sample candidate discussion](../candidate_discussion/) for reference, then continue to the
[final exercise](../).

Useful clarifications include cart shape, stock reservation, payment outcomes, duplicate requests, and what
happens when payment or stock allocation fails.
