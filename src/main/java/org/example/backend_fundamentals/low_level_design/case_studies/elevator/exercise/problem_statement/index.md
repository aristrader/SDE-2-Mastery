# Interviewer prompt — Elevator

> Design an elevator system.

This problem statement is intentionally vague. Review the
[sample candidate discussion](../candidate_discussion/) for reference, then continue to the
[final exercise](../).



How many elevators are we talking about?
Is the number of elevators fixed or more can be added?
Fixed floors or floors can be added or removed?
Elevator calling single button or dual button direction system?
Does lift do only 1 floor at a time, meaning if it is empty it can go to a floor, if it is occupied it will take only the input floors and stop in that order?
How to decide which lift to choose from?
Fixed lift capacity or any number of people can enter?
