# Exercise

## Exercise: timed-hld-framework - Run a 45-Minute HLD Mock

Pick one problem from `todo/study_plan/reference/PracticeProblems.md` Section 2.

Use this timing:

| Phase | Time |
|-------|------|
| Clarify scope | 5 min |
| Estimates | 5 min |
| High-level design | 10 min |
| Deep dive | 20 min |
| Wrap-up | 5 min |

Tasks:

1. Ask at least 5 clarification questions.
2. Write assumptions explicitly.
3. Produce at least one QPS or storage estimate.
4. Draw the high-level boxes and two concrete flows.
5. Deep dive into one bottleneck.
6. Name one alternative design and why you did not choose it.
7. End with monitoring, failure modes, and next scale step.

## Acceptance criteria

A good mock:

- does not jump straight to architecture
- has clear assumptions
- uses numbers to justify design choices
- explains tradeoffs
- finishes with operational thinking

## Quick recall

**Q. What is the biggest goal of the exercise?**  
A. Practice pacing and tradeoff narration, not memorizing a perfect architecture.
