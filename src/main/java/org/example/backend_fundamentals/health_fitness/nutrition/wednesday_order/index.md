# Wednesday Order

Order on Wednesday night. Covers Thursday, Friday, and Saturday breakfast/lunch.

## Groceries

| Category | Buy |
| --- | --- |
| Leafy greens | Palak or methi |
| Fast vegetables | Beans, bhindi, cucumber |
| Stable vegetables | Cabbage, cauliflower, carrot, beetroot |
| Protein | Eggs, curd/chaas, paneer/tofu, frozen chicken/fish |
| Carbs | Atta, rice, bread if needed |
| Fruit | Apple, banana, orange, guava, papaya |

## Meal Plan

| Day | Meal | A | B |
| --- | --- | --- | --- |
| Thursday | Breakfast | Besan chilla + curd | Moong dal chilla + curd |
| Thursday | Lunch | Chicken/fish/paneer + methi + 1-2 rotis | Dal + methi + curd + rice/roti |
| Thursday | Dinner | Moong dal + bhindi + salad | Eggs + bhindi + 1 roti |
| Thursday | Snack | Whey post-workout | Buttermilk or evening fruit |
| Friday | Breakfast | Poha/upma + curd | Eggs + toast |
| Friday | Lunch | Dal + carrot/beetroot salad + 2 rotis | Chicken/tofu + beans/seasonal sabzi + rice |
| Friday | Dinner | Rajma/chole leftovers + salad | Paneer/tofu + mixed vegetables |
| Friday | Snack | Fruit + curd | Boiled eggs or roasted chana |
| Saturday | Breakfast | Oats + milk | Eggs + toast |
| Saturday | Lunch | Paneer/tofu/chicken + seasonal sabzi + roti | Dal + sabzi + curd + rice |

Use leafy greens on Thursday first. Keep frozen chicken frozen until needed; use within 1-2 days after thawing.
