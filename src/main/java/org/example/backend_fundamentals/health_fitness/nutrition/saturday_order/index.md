# Saturday/Sunday Order

Order on Saturday evening or Sunday afternoon. Covers Sunday breakfast, Monday, Tuesday, and Wednesday breakfast/lunch.

## Groceries

| Category | Buy |
| --- | --- |
| Sunday basics | Oats, milk |
| Leafy greens | Palak or methi |
| Fast vegetables | Cucumber, tomato, beans/bhindi |
| Stable vegetables | Lauki, tori, cabbage, carrot, beetroot |
| Protein | Eggs, curd, paneer/tofu, frozen chicken/fish |
| Carbs | Atta, rice, oats, bread if needed |
| Fruit | Banana, apple, orange, guava, papaya |

## Meal Plan

| Day | Meal | A | B |
| --- | --- | --- | --- |
| Sunday | Breakfast | Oats + milk | - |
| Sunday | Lunch | Outside heavy meal | - |
| Sunday | Dinner | Outside lighter meal + dessert | - |
| Monday | Breakfast | Oats + milk + banana/apple | Moong dal chilla + curd |
| Monday | Lunch | Palak dal + 2 rotis + curd | Chicken/paneer/tofu + palak + 1-2 rotis |
| Monday | Dinner | Kali masoor dal + lauki/tori + salad | Egg bhurji + lauki/tori + 1 roti |
| Monday | Snack | Whey post-workout | Fruit + curd |
| Tuesday | Breakfast | Moong dal chilla + curd | Eggs + toast + fruit |
| Tuesday | Lunch | Rajma + rice + salad + curd | Paneer/tofu + beans + 1-2 rotis |
| Tuesday | Dinner | Chicken/fish + cucumber salad + 1 roti | Dal + beans/lauki + curd |
| Tuesday | Snack | Evening fruit | Roasted chana or boiled eggs |
| Wednesday | Breakfast | Eggs + toast + fruit | Oats + milk + fruit |
| Wednesday | Lunch | Chole + rice + salad | Kala chana + 2 rotis + curd |
| Wednesday | Snack | Whey | Fruit + curd |

Use leafy greens on Monday first. Keep frozen chicken frozen until needed; use within 1-2 days after thawing.
