# Daily Workouts

| Day | Workout | Focus |
| --- | --- | --- |
| Monday | [Workout A V1](./a/) | Squat, push, row, core |
| Tuesday | [Workout B V1](./b/) | Hinge, lunge, shoulders, posture |
| Wednesday | [Workout C V1](./c/) | Full body, carry, core |
| Thursday | [Workout A V2](./a/) | Squat variation, chest angle, row, core |
| Friday | [Workout B V2](./b/) | Hinge variation, single-leg, shoulders |
| Saturday | [Workout C V2](./c/) | Full body variation, carry, core |
| Sunday | [Recovery](./recovery/) | Light: full-body reset |

## Rules

| Item | Rule |
| --- | --- |
| Rest | 60-90 sec, 90-120 sec after hard leg sets |
| Effort | Stop with 2-3 clean reps left |
| Progress | Reps first, then range/angle, then load |
| Pain | Sharp pain, tingling, or gait change = stop |

A/B/C repeat with variants. Use V1 early week and V2 later week. Keep Sunday recovery easy.

## Coverage

| Area | Covered by | Limit |
| --- | --- | --- |
| Legs | Squat, lunge, sit-to-stand, wall sit | Good base |
| Glutes/hamstrings | Bridge, hinge, Romanian deadlift | Good base |
| Chest | Incline pushup, pushup plus | Good base; heavier chest waits for gym/dumbbells |
| Back | Rows, Y-T-W, reverse fly | Good base |
| Shoulders | Wall lean, lateral raise, Y-T-W, wall slides | Good rehab/base |
| Arms | Pushups, rows, curls, carries | Enough for now |
| Core | Dead bug, plank, side plank, bird dog, carries | Good base |
| Calves/shins | Calf raise, tibialis raise | Good base |
