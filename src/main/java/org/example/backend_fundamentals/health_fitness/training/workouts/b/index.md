# Workout B

| Order | V1 | V2 | Muscles | Sets x reps |
| --- | --- | --- | --- | --- |
| 1 | Hip hinge | Backpack Romanian deadlift | Hamstrings, glutes, spinal erectors control | 3 x 10-15 |
| 2 | Supported reverse lunge | Split squat to small range | Quads, glutes, adductors | 3 x 6-10/side |
| 3 | Wall lean hold | Pike/wall lean shoulder tap | Shoulders, serratus, core | 2-3 x 8-20 |
| 4 | Prone Y-T-W | Reverse fly with bottles | Lower/mid traps, rear delts, rotator cuff | 2 x 6-12 |
| 5 | Lateral raise with bottles | Front raise with bottles | Side/front delts | 2 x 10-12 |
| 6 | Side plank | Side plank reach | Obliques, glute medius, core | 2-3 x 8-25 sec |
| 7 | Bird dog | Bird dog hold | Core, spinal control, glutes | 2 x 8/side or 5 x 5 sec |
| 8 | Wall sit | Wall sit | Quads, glutes | 2-3 x 20-40 sec |

## Progress

| If | Then |
| --- | --- |
| Lunge hurts | Step-back tap |
| Neck tight in Y-T-W | Reduce range |
| Hinge easy | Add backpack load |
| Time short | Do first 6 movements only |
