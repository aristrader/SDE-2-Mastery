# Workout C

| Order | V1 | V2 | Muscles | Sets x reps |
| --- | --- | --- | --- | --- |
| 1 | Sit-to-stand | Chair squat | Quads, glutes | 3 x 8-15 |
| 2 | Incline pushup | Close-grip incline pushup | Chest, shoulders, triceps | 3 x 6-12 |
| 3 | Hip hinge | Single-leg hip hinge assisted | Hamstrings, glutes, spinal erectors control | 3 x 10-15 |
| 4 | Backpack row | Backpack row pause | Lats, rhomboids, biceps | 3 x 8-12 |
| 5 | Prone W raise | Prone Y-T-W | Traps, rhomboids, rear delts | 2 x 8-12 |
| 6 | Pushup plus | Close-grip incline pushup | Serratus, chest, triceps | 2 x 8-12 |
| 7 | Prone swimmers | Reverse snow angels | Rear delts, traps, rotator cuff | 2 x 8-12 |
| 8 | Bear plank hold | Plank shoulder tap elevated | Core, shoulders, serratus | 2-3 x 10-30 sec |
| 9 | Plank | Calf raise | Core, shoulders, calves | 2-3 x 15-30 sec or 15-20 |

## Progress

| If | Then |
| --- | --- |
| Hinge easy | Slow the lowering or use assisted single-leg hinge |
| Plank hurts back | Elevated plank or dead bug |
| Bear plank hard | Use regular elevated plank |
| Time short | Do first 6 movements only |
