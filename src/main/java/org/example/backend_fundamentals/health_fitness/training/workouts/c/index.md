# Workout C

| Order | V1 | V2 | Muscles | Sets x reps |
| --- | --- | --- | --- | --- |
| 1 | Sit-to-stand | Chair squat | Quads, glutes | 3 x 8-15 |
| 2 | Incline pushup | Close-grip incline pushup | Chest, shoulders, triceps | 3 x 6-12 |
| 3 | Backpack Romanian deadlift | Hip hinge | Hamstrings, glutes, spinal erectors control | 3 x 10-15 |
| 4 | Backpack/band row | Row elbows wide | Lats, traps, rhomboids, biceps, rear delts | 3 x 8-12 |
| 5 | Pushup plus | Backpack curl | Serratus, chest, biceps, forearms | 2 x 8-12 |
| 6 | Reverse fly with bottles | Farmer carry | Rear delts, traps, rotator cuff, grip, core | 2-3 x 10-45 sec |
| 7 | Farmer carry | Plank shoulder tap elevated | Grip, traps, core, shoulders | 2-3 x 8-45 sec |
| 8 | Plank | Calf raise | Core, shoulders, calves | 2-3 x 15-30 sec or 15-20 |

## Progress

| If | Then |
| --- | --- |

| Plank hurts back | Elevated plank or dead bug |
| Carry easy | Heavier bags |
