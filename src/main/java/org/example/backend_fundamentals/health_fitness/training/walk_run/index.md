# Walk Run

Run only after 45 min pain-free walks and 2 stable strength weeks.

## Session

| Step | Time | Work |
| --- | --- | --- |
| Warm-up | 10 min | Easy walk, ankle circles, leg swings, hip circles, arm swings |
| Main | 45-60 min | Walk now; later walk-jog |
| Cool-down | 5-10 min | Slow walk + nasal breathing |

## Progression

| Phase | Plan |
| --- | --- |
| Weeks 1-4 | Walking only |
| Start running | Walk 2 min, jog 30-60 sec, repeat 6-8 times |
| Limit | Max 2 run days/week at first |
| Stop | Knee pain rising or next-day flare |
