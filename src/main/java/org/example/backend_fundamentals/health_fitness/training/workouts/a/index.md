# Workout A

| Order | V1 | V2 | Muscles | Sets x reps |
| --- | --- | --- | --- | --- |
| 1 | Chair squat | Sit-to-stand slow lower | Quads, glutes, adductors | 3 x 8-12 |
| 2 | Incline pushup | Wide incline pushup | Chest, front delts, triceps | 3 x 6-12 |
| 3 | Backpack row | Towel/backpack row | Lats, rhomboids, biceps | 3 x 8-12 |
| 4 | Prone W raise | Prone Y-T-W | Rhomboids, mid/lower traps, rear delts | 2 x 8-12 |
| 5 | Glute bridge | Single-leg bridge assisted | Glutes, hamstrings | 2-3 x 8-15 |
| 6 | Wall slide | Pushup plus | Lower traps, serratus, shoulders | 2 x 8-12 |
| 7 | Dead bug | Hollow hold or dead bug | Core, lower-back control | 3 x 8-10/side or 10-20 sec |
| 8 | Calf raise | Calf raise pause | Calves | 2-3 x 15-20 |
| 9 | Tibialis raise | Tibialis raise | Shins, ankle balance | 2 x 12-15 |

## Progress

| If | Then |
| --- | --- |
| Top reps clean twice | Harder variation |
| Pushup too hard | Higher incline |
| Squat hurts | Higher chair or wall sit |
| Row feels awkward | Use a light backpack and pull elbows toward ribs |
| Time short | Do first 6 movements only |
