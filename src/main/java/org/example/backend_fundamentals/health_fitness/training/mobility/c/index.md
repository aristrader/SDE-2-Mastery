# Mobility C

Hips, glutes, lower back. Keep this because sitting and running both tighten the hips.

| Movement | Dose | Target |
| --- | --- | --- |
| Hip flexor stretch | 30 sec/side | Hip flexors |
| Hamstring stretch | 30 sec/side | Hamstrings |
| Figure-4 stretch | 30 sec/side | Glutes, piriformis |
| 90/90 hip switches | 8/side | Hip rotation |
| Adductor rock-back | 8/side | Inner thigh |
| Knee-to-chest stretch | 20 sec/side | Lower back, glutes |
| Glute bridge | 10-12 | Glutes |
| Dead bug | 8/side | Core, lower-back control |
