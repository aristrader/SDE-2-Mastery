# Mobility

Do mobility in the evening after office work. Keep it easy: the goal is to reduce desk stiffness, calm the body down, and keep posture muscles active.

Rotate A, B, C.

| Drill | Focus | Use |
| --- | --- | --- |
| [Mobility A](./a/) | Neck, shoulders, chest | Monday/Thursday |
| [Mobility B](./b/) | Thoracic spine, shoulder blades, posture | Tuesday/Friday |
| [Mobility C](./c/) | Hips, ankles, glutes, lower back | Wednesday/Saturday |
| [Anytime desk-pain reset](./desk_pain_reset/) | Lower back, high neck pain, rounded shoulders | Whenever needed |
| [Desk reset](./desk_reset/) | Quick posture break | Every 45-60 min |

Sunday: repeat the tightest area.

## Coverage

| Area | Covered by |
| --- | --- |
| Neck | Chin tucks, rotations, side bend, levator stretch |
| Shoulders/scapula | Shoulder rolls, scapular retractions, wall slides, wall angels |
| Chest/lats | Doorway chest stretch, desk lat stretch |
| Thoracic spine | Cat cow, chair extension, thoracic rotation, thread-the-needle |
| Hips/glutes | Hip flexor stretch, 90/90 switches, figure-4, glute bridge |
| Hamstrings/adductors | Hamstring stretch, adductor rock-back |
| Ankles/calves | Ankle rocks, calf stretch |
| Core/back control | Dead bug, bird dog, pelvic tilt |

## Rules

- Use dynamic mobility before training; use longer static holds after training or in the evening.
- Stretches should feel like tension, not sharp pain.
- Strength work still matters: mobility keeps range; strength helps control that range.
