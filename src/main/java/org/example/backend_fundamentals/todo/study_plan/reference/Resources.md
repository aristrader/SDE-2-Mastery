# Resources by Format

Reference list of books, videos/courses, blogs/newsletters, and tools that show up across the study-plan track. Not part of the study plan itself — kept separate so the per-Part docs stay focused on topics, not references.

Use this as a lookup. Don't try to read everything. Pick one book per Part-cluster when you reach that phase of the study plan — DDIA when you hit Databases + HLD, JCIP when you hit Concurrency, Bulletproof TLS when you hit Security stack, etc.

---

## Books — the canonical ones

- *Designing Data-Intensive Applications* — Martin Kleppmann (the single most important book)
- *Database Internals* — Alex Petrov
- *Java Concurrency in Practice* — Brian Goetz
- *Effective Java* — Joshua Bloch
- *Spring in Action* — current edition
- *Release It!* — Michael Nygard (resilience patterns)
- *System Design Interview Vol 1 & 2* — Alex Xu
- *Bulletproof TLS and PKI* — Ivan Ristić
- *Serious Cryptography* — Jean-Philippe Aumasson
- *Designing Distributed Systems* — Brendan Burns
- *Refactoring* — Martin Fowler
- *Head First Design Patterns*
- *Domain-Driven Design Distilled* — Vaughn Vernon (gentle DDD intro)
- *Site Reliability Engineering* — Google (free online)
- *Hands-On Large Language Models* — Jay Alammar
