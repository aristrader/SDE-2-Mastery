The objective is **not** to learn DSA from scratch. The objective is to build Java coding fluency while revising the highest-ROI interview problems.

Group the curriculum into major DSA topics (Arrays, Strings, Linked Lists, Stacks & Queues, Binary Search, Trees, BSTs, Heaps, Graphs, Backtracking, Greedy, Sliding Window, Two Pointers, Intervals, Dynamic Programming, Tries, Bit Manipulation, etc.).

For each topic:

* Curate **3–5 representative, high-ROI interview problems**.
* Prefer problems from well-known interview lists such as Striver SDE Sheet, Blind 75, NeetCode, or equivalent.
* Maximize interview coverage rather than problem count.
* Group similar problems into families where appropriate. Choose one representative problem and list common interview variants alongside it.
* Include a link to the problem (preferably LeetCode, otherwise GeeksforGeeks).

Order the topics from highest interview ROI to lowest.

Do not explain algorithms or solutions. The output should be a structured checklist for Java DSA practice.
